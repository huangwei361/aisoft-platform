```
# 英语口语练习小程序首页 · 开发级 Prompt
（包含完整页面结构、交互逻辑、数据字段、像素风渲染规范，可直接生成可运行的小程序页面原型，而非空壳）

## 一、页面全局定义

- 页面类型：微信小程序首页 / 移动端竖屏 H5，尺寸适配 375px-430px 宽度屏幕
- 产品定位：像素风英语口语 A1 训练工具首页，核心作用是功能导航、学习数据展示、快速入口
- 整体布局：
  - 顶部：系统状态栏 + 品牌头部区（固定）
  - 上部：数据看板模块（固定）
  - 中部：核心功能入口 + 推荐主题 + 训练记录（可垂直滚动）
  - 底部：Tab 导航栏（固定悬浮）
- 交互框架：所有可点击元素带按压反馈，页面跳转路由自定义，数据用模拟真实值

## 二、全局模块功能与交互规范（逐模块开发指令）

### 模块 1：顶部系统栏 + 品牌头部区

- 系统状态栏：模拟微信小程序原生顶部，左侧显示时间「22:06」，右侧显示信号、Wi-Fi、电量图标；右上角保留小程序胶囊按钮
- 品牌头部：
  - 主标题：「英语口语练习」，居中，像素艺术字
  - 左侧角色：Q版像素女孩（棕色长卷发 + 红色蝴蝶结 + 黄色内搭 + 蓝色背带裤），挥手姿势，搭配白色对话气泡，气泡文字「Hi，Vicky 喊你练口语啦！」
  - 右侧装饰：白色像素美式窗 + 爱心气泡 + 拱形窗 + 盆栽 + 堆叠书本 + 远山蓝天白云背景
  - 交互：头像为展示区，无点击事件

### 模块 2：数据看板模块（3 个指标卡片）

- 3 卡片横向等分排列，卡片间距 16rpx，整体左右留边 32rpx
- 卡片样式：白色底色，像素圆角，浅灰像素描边框，文字上下排版，图标左对齐
- 数据：连续打卡 12 天 ｜ 当前等级 Lv.7 ｜ 今日目标 15 分钟

### 模块 3：核心功能入口区（3 个大功能卡片）

- 纵向排列，卡片间距 28rpx，左右留边 32rpx，每张卡片高度 120rpx

**卡片 1：自由对话（一级入口）**
- 背景色：浅粉渐变 #FFB6C1 → #FF9AA2
- 左侧：红色像素麦克风 + 声波特效图标
- 文字：主标题「自由对话」（加粗黑色，36rpx），副标题「像美国朋友一样自然聊天」（白色，24rpx）
- 右侧：白色像素箭头按钮
- 交互：点击整张卡片跳转「AI 自由对话聊天页」，点击时有 0.95 倍缩放按压效果

**卡片 2：生成训练材料**
- 背景色：浅橙黄渐变 #FFE29A → #FFCC66
- 左侧：像素黄色桌面图标（电脑 + 台灯 + 书本 + 办公椅）
- 文字：主标题「生成训练材料」（加粗深棕，36rpx），副标题「对话 / 故事 / 演讲 / 场景练习」（深棕，24rpx）
- 右侧：浅金色像素箭头按钮
- 交互：点击整张卡片跳转「训练材料生成页」，点击时有 0.95 倍缩放按压效果

**卡片 3：今日复习**
- 背景色：浅绿色渐变 #B5EAD7 → #8DD8B0
- 左侧：像素书本 + 怀表 + 宝箱组合图标
- 文字：主标题「今日复习」（加粗深绿，36rpx），副标题「待复习：8 个单词 · 5 个句子」（深绿，24rpx）
- 右侧：彩色实心按钮「立即开始」（白色文字，像素圆角）
- 交互：点击按钮或整卡跳转「复习训练页」，按钮点击时颜色加深 10%

### 模块 4：今日推荐主题区

- 标题栏：左侧星星图标 + 文字「今日推荐主题」（32rpx，加粗深灰）；右侧「换一换」文字按钮 + 刷新图标（28rpx）
- 主题卡片：3 张横向等分排列，间距 16rpx
- 单张卡片结构：
  - 顶部：像素场景插画（占卡片高度 70%）
  - 中部：主题名称（30rpx，居中，深灰）
  - 底部：星星评分（4 颗半星，黄色像素星星）
  - 左上角：爱心收藏图标（「餐厅点餐」为红色实心选中态，其余为空心）
- 三个主题默认值：餐厅点餐、聊工作、旅行英语
- 交互：
  - 点击主题卡片 → 跳转对应场景的专项训练页
  - 点击爱心 → 切换收藏状态（实心 / 空心切换）
  - 点击「换一换」→ 随机刷新 3 个新的推荐主题

### 模块 5：最近训练记录区

- 标题栏：左侧训练图标 + 文字「最近训练记录」（32rpx，加粗深灰）；右侧「查看更多」文字按钮（28rpx，浅灰）
- 记录列表：纵向排列 2 条记录，单条记录高度 100rpx，白色底色，像素圆角
- 单条记录字段（从左到右）：
  - 左侧：主题像素图标（行李箱 / 餐具）
  - 中上：日期 + 主题名称（例：7 月 25 日 聊旅行，30rpx，深灰）
  - 中下：时长 + 表现星级（例：时长 18 分钟｜表现 ★★★★，24rpx，浅灰）
  - 右侧：XP 值标签（例：92 XP，白色文字）+ 灰色箭头
- 模拟数据：
  - 7 月 25 日 聊旅行 ｜ 18 分钟 ｜ 4 星半 ｜ 92 XP ｜ 行李箱图标
  - 7 月 24 日 餐厅点餐 ｜ 15 分钟 ｜ 4 星半 ｜ 86 XP ｜ 餐具图标
- 交互：
  - 点击单条记录 → 跳转该次训练的详情复盘页
  - 点击「查看更多」→ 跳转完整历史记录页

### 模块 6：底部 Tab 导航栏

- 固定在页面最底部，高度 100rpx，白色底色，顶部 1px 浅灰像素分割线
- 4 个 Tab 横向均分，每个 Tab = 顶部像素图标 + 底部文字
- Tab 状态：
  - 首页：像素小房子图标 + 「首页」文字 → 选中态（粉红色）
  - 练习：宝剑图标 + 「练习」文字 → 未选中（深灰色）
  - 收藏复习：宝箱图标 + 「收藏复习」文字 → 未选中（深灰色）
  - 历史：卷轴图标 + 「历史」文字 → 未选中（深灰色）
- 交互：点击 Tab 切换对应页面，选中 Tab 图标 + 文字同步变为主题粉红色

## 三、像素视觉渲染特殊规范

- 风格基调：8-bit 复古像素艺术风，所有视觉元素均由像素模块构成，无平滑抗锯齿；整体治愈明亮，偏日式 RPG 游戏色彩系统（使用固定色值）

**像素元素规范**
- 基础像素网格：16×16 像素精度，所有图标统一网格体系
- 圆角规则：像素化圆角（8px 对应像素系圆角），无平滑圆角
- 阴影：轻微像素投影，2px 向下偏移，浅灰色，无模糊渐变

**排版规范**
- 一级标题：36rpx，加粗，像素字体风格
- 二级标题：32rpx，加粗
- 正文 / 说明：24-28rpx，常规字重
- 所有文字居中 / 对齐严格按照像素模块规范，行高 1.4 倍

**插画细节要求**
- 角色：Q 版二头身，线条柔化，色彩平涂，无渐变阴影
- 场景元素：每个功能图标都是独立像素插画，识别性强，风格统一
- 背景元素：云朵、远山、植物均为像素块拼接，层次分明

## 四、输出与技术要求

- 输出格式：输出完整的小程序页面代码（WXML 结构 + WXSS 样式 + JS 交互逻辑），或对应 Coze 可视化组件的完整配置
- 适配要求：使用 rpx 响应式单位，兼容 iOS / 安卓主流机型，底部适配安全区域
- 交互实现：所有点击、按压、状态切换、跳转路由均需实现效果，使用模拟数据渲染
- 还原度要求：严格按照上述像素风格、色值、布局比例还原，不得自动简化模块或更改结构
- 可扩展性：数据字段预留接口，后续可对接真实后端数据替换模拟值
```
